# Security

Relay launches coding tools that can modify local repositories.

Security issues involving project routing, process execution, command injection, credential leakage, ingress trust, or unsafe extension behavior should be treated as high priority.

The project is currently private.

Before public release, this file must be updated with a private vulnerability reporting channel.

For the current security design, see:

- `docs/security-model.md`
- `docs/adr/0005-external-process-extension-direction.md`
- `docs/adr/0007-cli-first-git-github.md`
