# Status — August 2026

A point-in-time summary of what actually works, what does not, and which
decisions are open. Milestone tracking lives on the M-ladder (M1 through M8.1);
see [docs/M8_1_PACK/RELAY_M8_1_SEQUENTIAL_IMPLEMENTATION_PACK/00-IMPLEMENTATION-SEQUENCE.md](M8_1_PACK/RELAY_M8_1_SEQUENTIAL_IMPLEMENTATION_PACK/00-IMPLEMENTATION-SEQUENCE.md).

## What Works End to End Today

The working path is entirely local:

```text
local paste / file import
    ->
review
    ->
explicit Run approval
    ->
Codex runtime
    ->
events / diff / logs
```

Details:

- local ingress accepts canonical JSON files and paste, with optional Markdown
  wrappers containing the same JSON block ([docs/local-ingress.md](local-ingress.md));
- Codex runs through the `codex app-server` transport by default; `codex exec`
  remains available;
- a second runtime (Antigravity) is wired through RuntimeRouter with
  ExecutionRunPolicy freezing provider/profile/model/reasoning per execution;
- the TUI provides a command palette, model/reasoning selectors, Diff and Logs
  screens, a Doctor view, and a permission broker with scoped grants.

Milestones M1 through M8 are complete. M8.1 is mostly landed: pack items 01–03
are done; items 04–05 are partial (provider-neutral Markdown rendering and full
scrollable execution/result UX polish remain).

## Known Gaps

- **GitHub ingress / binding: does not exist.** There is no `gh` adapter crate.
  GitHub appears only as expected-remote metadata in repository safety checks.
  The roadmap's v0.1 GitHub leg is planned, not started.
- **Relay Direct / MCP submission transport: does not exist.** No
  `submit_handoff` boundary or MCP packaging exists in code.
- **Planner-adapter conformance harness: documentation only.**
  [docs/planner-adapter-conformance.md](planner-adapter-conformance.md) defines
  cases, but no executable harness enforces them.
- M8.1 pack items 04–05 are partial (Markdown rendering clarity, scrollable
  execution/result completion).
- **Distribution posture:** routing among registered runtimes and bounded
  cross-provider concurrency work today; fan-out, health-aware routing, and
  cross-provider aggregation are design intent only
  ([ADR-0018](adr/0018-provider-distribution-model.md)).

## Open Decision — RESOLVED

Resolved by [ADR-0016](adr/0016-mcp-first-submission-and-v0-1-local-descope.md):

- v0.1 ships with local file/paste as the only ingress (explicit descope of the
  GitHub leg).
- Relay Direct/MCP is the first automatic submission transport, implemented as
  milestone M9
  ([docs/M9_PACK](M9_PACK/RELAY_M9_MCP_DIRECT_IMPLEMENTATION_PACK/00-IMPLEMENTATION-SEQUENCE.md)).
- Submission investments are layered by dependency durability: local fallback,
  MCP open protocol, optional host-agnostic GitHub bridge; host-specific glue
  never enters core code.
