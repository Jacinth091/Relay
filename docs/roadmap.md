pointer, not the roadmap itself.

## Current development

- **[Architecture v2 phase status & roadmap](v2_architecture_rebaseline/ROADMAP.md)** — authoritative.
  Read this for what is done, partial, or not started.
- **[ADR-0020: Relay Architecture v2](adr/0020-relay-architecture-v2.md)** — the architecture
  authority.
- **[Implementation sequence](v2_architecture_rebaseline/02-IMPLEMENTATION-SEQUENCE.md)** — the
  16 dependency-ordered vertical slices (phases 00–15).

There is deliberately **no** separate optimistic roadmap here. A phase is not
complete until its production exit gate is proven; module or test presence alone
is not completion.
