# Third-Party Notices

Relay may reference, depend on, or learn from other open-source projects and libraries. This file is used to document third-party material when a license or attribution notice needs to be preserved.

## Current Status

Relay does not currently include copied or vendored source code from AIF Handoff.

AIF Handoff is mentioned in `ACKNOWLEDGMENTS.md` and `docs/inspiration-and-positioning.md` as one of the projects that helped inform some of Relay's architectural thinking.

If Relay later incorporates source code, documentation, assets, or other material from a third-party project, the appropriate attribution and license notices will be included here or alongside the relevant files.

Dependencies installed through package managers retain their respective licenses. Before a public release, Relay's release process should also provide a dependency license inventory where appropriate.
